# CW练考通 产品改进方案

> 版本：V1（评审稿）　基线：`V3.0.3`（`com.wc.cwtrainer`，minSdk 26 / targetSdk 34）
> 编写依据：现有 Android 工程源码与资源，未做用户访谈，属「代码事实 + 产品推演」，评审时请重点确认第 2、5 节的取舍。

---

## 1. 结论先行

**现状**：这是一个功能密度很高、但产品结构偏「老手自制工具」的训练器。

- 内容深度领先：CW / SSB 双模式赛事模拟、15 国台站与 3 种口音变体、45 套 SSB 真人语音包（约 1800 个词条）、B/C 类共 2423 道题、麦克风实时解码。
- 结构缺口明显：没有 A 类题库、没有新手引导、没有训练历史与复习机制、没有跨设备数据、没有支付通道。

**判断**：短期不需要加更多「炫技功能」，应先把**新手可进入、训练可闭环、成绩可带走**这三件事补齐；创新点与商业化都应长在这三条主线上。

---

## 2. 目标用户与核心场景

| 人群 | 占比预估 | 核心诉求 | 现状满足度 |
|---|---|---|---|
| 新手（准备 A 类 / 刚拿呼号） | 最大 | 从哪开始、每天练什么、能不能考过 | 低（无 A 类、无引导、无计划） |
| 备考 B/C 类 | 中 | 刷题效率、错题、模拟考 | 高（题库全、有错题本与模拟考） |
| 竞赛 / 老手 | 小但口碑关键 | 听抄速度、真实赛事环境、成绩复盘 | 高（赛事模拟强）但产出缺失 |

核心场景排序（决定首页与优先级）：

1. 每天 10 分钟碎片训练（背码 / 听抄）
2. 考前两周集中刷题 + 模拟考
3. 赛前专项听抄与口音适应
4. 换设备 / 换平台后继续练

## 3. 现状诊断

### 3.1 用户视角

| # | 问题 | 证据 | 影响 | 改进方向 |
|---|---|---|---|---|
| U1 | 无 A 类题库，新手无法从第一关开始 | `core/Exam.kt` 的 `ExamLevel` 仅 `B`、`C`；`assets/question_bank_2025.json` 仅 `B`(1142)、`C`(1281) | 最大人群直接流失 | 补 A 类题库；考试页按「A→B→C」呈现升级路径 |
| U2 | 首页五个平行入口，无推荐 | `ui/screens/HomeScreen.kt` 01–05 卡片 | 新手随机点、次日不回访 | 首启 30 秒自测 → 生成训练计划；首页顶部「今日 3 件事」 |
| U3 | 训练数据只有 4 个数字 | `core/Prefs.kt` 的 `StatsStore`：`learnCorrect/learnTotal/copyBest/contestBest` | 看不到进步，缺乏坚持动机 | 增加历史记录、连续天数、单字符掌握度、错误分布 |
| U4 | 无复习机制 | 背码为随机出题（`LearnScreen`），无调度 | 违背遗忘曲线，练了就忘 | 引入 SRS（间隔重复）与「今日待复习」 |
| U5 | 数据不可导出、换机即清零 | 全量存 `SharedPreferences`，全工程无导出/备份/账号代码 | 长期用户流失成本高 | 本地导出/导入 + 账号云同步 |
| U6 | 缺少装备与传播知识 | 无相关页面 | 新手第二大需求无人承接 | 内容卡片 / 外链专栏（可后置） |

### 3.2 人机交互视角

| # | 问题 | 证据 | 影响 | 改进方向 |
|---|---|---|---|---|
| I1 | 无音频焦点管理、无前台服务、无常亮 | 各播放器仅 `setAudioAttributes`（`core/Sidetone.kt`、`CwAudio.kt`、`VoiceBank.kt`、`RadioVoice.kt`、`VoiceSynth.kt`），全工程无 `requestAudioFocus` / `FOREGROUND_SERVICE` / `setKeepScreenOn` | 来电、通知、蓝牙切换、锁屏会中断播报；赛事听抄熄屏即断 | 统一 AudioEngine：申请焦点、处理 `AUDIOFOCUS_LOSS_TRANSIENT`、前台服务 + 常亮开关 |
| I2 | 导航为单根栈，二级页只能回首页 | `MainActivity.kt` 的 `AppScreen` 枚举 + `BackHandler` | 深链缺失、跨模块跳转困难 | 底部导航（训练 / 考试 / 工具 / 我的）+ 保留返回栈 |
| I3 | 设置项 18 项平铺，术语无解释 | `core/Prefs.kt` 的 `SettingsData`；`SettingsScreen.kt` 五组平铺 | 新手劝退，误设后不知如何恢复 | 预设档位（新手/进阶/竞赛）+ 术语 tooltip + 恢复默认 |
| I4 | 自定义 Canvas 无无障碍描述 | 瀑布图、S 表等绘制组件 | TalkBack 用户不可用；也不利于截图分享 | 补充 `contentDescription` 与文字化摘要 |
| I5 | 无横屏 / 平板布局、未验证字体缩放 | `AndroidManifest.xml` 锁定 `screenOrientation="portrait"`；各 Screen 均为单列 `Column` | 大屏体验差，老年用户（业余无线电核心人群）阅读吃力 | 平板双栏、字体缩放适配、关键数值放大模式 |

### 3.3 无线电爱好者需求

| # | 缺口 | 现状 | 价值 |
|---|---|---|---|
| R1 | 赛事只「听」不「交」 | 有 CW/SSB、噪声、衰落、S 表，但无日志与成绩产出 | 增加 ADIF / Cabrillo 导出、分数复盘，练完能带走 |
| R2 | 无 QSO 全流程训练 | 只有抄收，没有发报对话、交换流程、pileup 抢答 | 从「能抄」到「能通」，是进阶刚需 |
| R3 | 无传播与波段认知 | 无太阳指数、昼夜波段特性 | 进阶内容，可做订阅增值 |
| R4 | 无装备/天线入门 | 完全空白 | 新手第二大问题，可做内容或导购合作 |
| R5 | 无社区与约练 | 无账号体系 | 打卡、排行、俱乐部，是留存与 B 端入口 |

## 4. 创新点（差异化）

| # | 创新点 | 解决的问题 | 关键实现 | 差异化 | 依赖 |
|---|---|---|---|---|---|
| 1 | **虚拟赛场** | 真实竞赛环境难获取 | 多台站并发 + pileup + 传播起伏 + 计时；结束生成成绩单与失误热力图 | 同类极少把「赛事」做成完整闭环 | 现有 `core/Contest.kt` 扩展 |
| 2 | **口音适应训练** | 听不懂非母语口音 | 基于 45 套语音包（`assets/ssb/*`）做「国家口音关卡」，逐词命中率评分 | 独有资产，别人没有 1800 条真人词 | 现有 VoiceBank |
| 3 | **手机即解码器 / 电键** | 缺少低成本练习硬件 | 麦克风实时解码 + 屏幕手键/自动键；扩展 BLE 电键、音频线接电台中频 | 从 App 变成外设入口 | `ToneKeyDetector`、`MorseDecoder` |
| 4 | **AI 教练** | 用户不知道该练什么 | 依据错题与混淆模式（E/I、S/H、5/H）生成专项组；语音点评 | 从「题库」升级为「教练」 | 统计数据 + 规则引擎，LLM 可选 |
| 5 | **训练护照** | 缺成就感与传播 | 连续天数、段位、赛事成绩卡片可分享 | 低成本传播，形成练—赛—晒循环 | 统计体系 |

> 建议顺序：先 1、3（能力已有，包装即可），再 2、5（依赖统计），最后 4（依赖数据积累）。

## 5. 商业化方案

### 5.1 前提：先解决「收得到钱」

当前通过 Gitee / GitHub 自更新分发（`core/UpdateManager.kt`，双源查版本 + 下载 APK 安装），**没有任何支付通道，也不符合应用商店内购规则**。三条路径：

1. 上架国内安卓商店（华为/小米/OPPO/vivo/应用宝），分成约 30–50%，可接官方支付；
2. 自建「授权码 + 服务端校验」：App 内下单跳转 H5 支付，服务端签发授权，需处理支付合规与退款；
3. **以 Web 版（HMA 研习社）为收银台**：网页端订阅，App 扫码登录共享权益——改动最小、最合规，推荐优先。

iOS 若要收费必须走 App Store 内购（小型开发者计划 15%）。

### 5.2 分层与定价

| 层级 | 内容 | 定价建议 | 目的 |
|---|---|---|---|
| 免费 | 现有全部训练、B/C 题库、基础语音包、每日 1 次模拟考 | 0 | 口碑与规模 |
| 内容包 | A 类题库、年度新题库、专项题包（法规 / 天线 / 操作） | 6–18 元 / 个 | 低门槛首单 |
| 会员 | 云同步（App + Web）、AI 教练、无限模拟考、成绩报告导出（PDF/CSV）、高级赛场 | 18–30 元/月，98–168 元/年 | 主收入 |
| 买断 Pro | 解锁全部场景与导出、永久去限制 | 68–128 元 | 老手偏好 |
| B 端 | 俱乐部/培训机构/考点：班级管理、教练看板、批量授权 | 按人数年费 | 稳定现金流 |
| 硬件联动 | 电键/解码盒联名分成、训练套件 | 分成或差价 | 生态 |

### 5.3 转化路径

首启自测 → 免费完成第一周计划 → 第 7 天展示「你的进步报告」→ 解锁会员（云同步 + 报告导出 + AI 教练）。
关键：**免费必须能完整考过 B/C**，收费只卖「效率、跨端、复盘、进阶内容」。

### 5.4 合规与风险

- **题库版权**：官方题库公开，但整理版、解析、图片的再分发需确认授权；对外不宣称「官方」。
- **考试不承诺包过**：宣传用语避免「保过」「押题」。
- **支付合规**：自建支付需主体资质与退款机制；优先 Web 订阅。
- **iOS 缺席**：当前只有 Android，跨端故事需 Web 补齐。

## 7. 指标与验收

- **北极星**：周活跃训练次数（每周完成 ≥3 次训练的用户占比）。
- **首启漏斗**：安装 → 打开 → 完成自测 → 完成首次 10 分钟训练 → 次日回访，逐级埋点。
- **质量**：音频中断类反馈数、崩溃率、导入/导出成功率。
- **商业化**：7 日免费转付费率、会员月续费率、Web→App 拉新占比。

> 当前工程无任何埋点与崩溃上报，P0 阶段建议先接入轻量统计（可自建，注意隐私合规）。

## 8. 风险与依赖

1. **内容风险**：A 类题库与解析的版权、更新频率；口音关卡涉及语音包授权范围。
2. **技术风险**：前台服务与省电策略适配（国产 ROM 后台限制）；SRS 与统计的数据迁移。
3. **商业风险**：应用商店审核（无线电考试类目）、支付合规；自更新分发与商店分发的双轨维护成本。
4. **组织依赖**：云同步需要后端（可复用 HMA 研习社的账号与同步接口）。
