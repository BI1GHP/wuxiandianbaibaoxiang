# CW练考通 · 视觉、品牌与双主题升级方案

> 版本：V1（建议稿）　基线：`V2.09`　配套文档：[产品改进方案.md](产品改进方案.md)
> 说明：本文是**设计建议**，不含代码改动；第 9 节的落地路径可直接拆成开发任务。

---

## 1. 结论先行

1. **双主题不是"粉红滤镜"，而是两套设计语言**：一套「野战电台」（军规、金属、LED），一套「奶油手帐」（纸感、贴纸、圆角）。共用同一套信息架构与组件 API，只换 Design Token、插画与音效包。
2. **命名建议主推「滴答电台 / DitDah」**，保留「CW 练考通」作为商店副标题承接搜索流量；理由与备选见第 4 节。
3. **图标要能被 0.5 秒认出来**：应用图标用「S 表指针 + 点划」符号，功能图标统一 24dp / 2dp 线宽，女性主题只换配色不换轮廓，保证品牌识别一致。
4. **独一无二的抓手是"氛围 + 产出"**：开机自检动画、旋钮/继电器音效、QSL 卡片成绩单、桌面小组件——这些是同类 CW App 普遍缺失的，而不是再加一个题库。
5. **商业化只卖"表达"，不卖功能**：皮肤、QSL 模板、桌面小组件、联名配色；训练与考证能力保持免费（与产品改进方案的定价策略一致）。

## 4. 品牌命名建议

### 4.1 命名标准

- 2–3 个音节，中文可读、英文可拼、可注册拼音域名；
- 能覆盖"练习 + 考证 + 赛事"三类场景，不锁死在考试；
- 不出现"包过 / 押题 / 官方"等合规风险词；
- 有画面感，能支撑双主题（机械 / 温柔都不违和）。

### 4.2 候选清单

| 名称 | 含义 | 适配双主题 | 风险 | 评分 |
|---|---|---|---|---|
| **滴答电台 / DitDah** | 点划的拟声，最 CW、最好记 | 高（机械=滴答声，可爱=滴答钟） | 英文 DitDah 有少量同名小工具，需查商标 | ★★★★★ |
| 电波手帐 / WaveNote | 记录每一次通联与训练 | 高（手帐天然偏柔，机械风做"航海日志"） | "手帐"可能弱化考试属性 | ★★★★ |
| 摩斯方舟 / MorseArk | 承载爱好者社群 | 中 | 略宏大，偏社区 | ★★★ |
| 呼号牌 / CallPlate | 火腿身份符号 | 高 | 未取得呼号的新手无感 | ★★★ |
| 火腿自习室 / HamStudy | 学习场景直白 | 中 | 与 HamStudy.org 名称冲突 | ★★ |

### 4.3 推荐组合

- **商店名**：滴答电台 · CW 训练与考证
- **桌面名**：滴答电台（4 字，图标下不折行）
- **搜索副标题（保留 SEO）**：CW练考通 · 业余无线电 A/B/C 题库
- **英文名**：DitDah（图标角标可用 `DIT·DAH`）
- **改名节奏**：先在关于页/启动页露出新名，商店名与图标同批更新，避免只改一半造成认知割裂。

## 5. 双主题设计语言

### 5.1 主题 A｜野战电台（默认，面向机械/设备爱好者）

| Token | 值 | 用途 |
|---|---|---|
| `bg` | `#12161C` | 机身深灰 |
| `surface` | `#1E242D` | 凸起面板 |
| `surfaceSunken` | `#0A0D11` | 凹槽屏幕 |
| `line` | `#2A3240` | 分割线 / 1dp 边框 |
| `accent` | `#FFC857` | 琥珀 LED，主操作 |
| `accentAlt` | `#3DDC97` | 正确 / 通过 |
| `info` | `#00D4FF` | S 表 / 波形 |
| `danger` | `#FF4444` | 错误 / 超时 |
| `text` | `#E6EDF7` | 主文字 |
| `textDim` | `#7A8599` | 次要文字 |

- **形状**：圆角 2–6dp，硬边、细描边、内阴影；按钮像"物理按键"，按下位移 1dp。
- **材质**：拉丝金属渐变（现有首页卡片可换成 135° 细纹理）、螺丝/铭牌装饰只出现在页头，不进入内容区。
- **字体**：标题用思源黑体 Heavy；频率、码速、计时用等宽数字（Roboto Mono / DIN 风格）。
- **动效**：80–140ms 线性或快速减速，模拟表针与继电器；不使用弹跳。
- **声音**（可选开关）：旋钮卡位、PTT 咔哒、继电器吸合。

### 5.2 主题 B｜奶油手帐（面向女性爱好者与轻度用户）

| Token | 值 | 用途 |
|---|---|---|
| `bg` | `#FFF7F2` | 奶油纸底 |
| `surface` | `#FFFFFF` | 卡片 |
| `surfaceAlt` | `#F6F1E4` | 米黄纸（沿用考试页） |
| `line` | `#EFE3D8` | 分隔线 |
| `accent` | `#FF8FA3` | 珊瑚粉，主操作 |
| `accentAlt` | `#7FD1C1` | 薄荷绿，正确 |
| `warn` | `#FFD166` | 提醒 / 待复习 |
| `ink` | `#3A362E` | 正文墨色 |
| `inkDim` | `#8E8776` | 铅笔灰 |

- **形状**：圆角 16–24dp，柔和投影（y=4, blur=16, alpha=0.06），卡片可轻微旋转 -0.5° ~ 0.5° 模拟贴纸。
- **材质**：纸胶带、手绘点划、圆点网格背景；插画用单色线稿 + 两色平涂，避免廉价 3D 卡通。
- **字体**：标题可用霞鹜文楷（开源）或圆体，数字仍用等宽，保证读数专业。
- **动效**：220–320ms 弹簧曲线，翻页/贴纸吸附感。
- **声音**：轻打字机、木鱼轻点（默认音量低于主题 A）。

### 5.3 双主题的三条硬规则

1. **同构**：信息架构、页面层级、按钮位置完全一致，只换皮肤；切换主题不改变任何操作路径。
2. **不是反色**：两套是独立色板与形状体系，不是给深色加粉。两套都必须过 WCAG AA（正文对比度 ≥ 4.5:1）。
3. **Token 化落地**：把 `Theme.kt` 的全局 `val` 重构为 `WcColors` 数据类 + `CompositionLocal`，页面只引用 `LocalWcColors.current`，避免逐页改色。主题偏好存入 `AppPrefs`（新增 `theme` 字段，导出备份自动带上）。

## 7. 图标系统

### 7.1 应用图标（3 个概念，建议选 1）

| 概念 | 描述 | 优点 | 风险 |
|---|---|---|---|
| **A. S 表指针 + 点划** | 圆形表盘，指针指到右上，底部一条 `·—·—` 点划 | 0.5 秒识别"电台 + 摩斯"，缩放后仍清晰 | 需控制细节，避免小尺寸糊 |
| B. 呼号铭牌 | 金属铭牌 + `CW` 刻字 | 机械感最强 | 与考试/学习关联弱 |
| C. 旋钮 | 侧视旋钮 + 刻度环 | 硬件感强 | 像相机/音响 App |

推荐 A：
- 自适应图标：前景 108×108dp，安全区 66dp，点划放安全区底部；
- Android 13 单色主题图标：只保留表盘轮廓 + 点划；
- B 主题版本：同一轮廓，奶油底 + 珊瑚指针（**换色不换形**，保持品牌一致）；
- 商店截图第一张必须露出该图标元素与"点划"符号，形成记忆锚点。

### 7.2 功能图标（24dp，2dp 线宽，圆头端点）

| 模块 | 图形语义 |
|---|---|
| 听抄练习 | 耳机 + 声波弧线 |
| 背码训练 | 两张点划卡片叠放 |
| 赛事听抄 | 天线塔 + 发射波纹 |
| CW 翻译器 | 手键 + 波形 |
| 业余无线电考试 | 试卷 + 徽章 |
| 设置 | 旋钮（不用齿轮，强化设备感） |
| 继续训练 | 回放箭头 + 点划 |

规则：图标一律描边、不加多色；当前选中态用主题 `accent` 填充 8% 底。

## 8. 独一无二的亮点（建议优先做的 5 个）

1. **双设计语言，而非双配色**：同类产品最多提供深浅色；我们提供"两种人格"，且共享同一套组件，维护成本可控。
2. **QSL 卡片式成绩单**：把听抄正确率、赛事得分、考试通过记录生成一张可保存/分享的 QSL 卡（呼号、日期、报告、印章）。火腿文化里 QSL 卡是硬通货，天然愿意晒，且可做付费模板。
3. **开机自检动画 + 声音品牌**：3 秒内完成"电台开机"叙事，配合可关闭的继电器/旋钮音效。这是极低成本、极高辨识度的差异点。
4. **主题即"电台皮肤"**：以真实机型配色为灵感做皮肤（军绿、沙漠黄、奶油白、深海蓝），后续可与国产手台/天线品牌联名。卖的是身份表达，不是功能。
5. **桌面小组件**：S 表时钟（当前码速/今日待复习）+ 一键进入继续训练。小组件是安卓端被严重低估的留存入口。

补充（第二阶段）：**呼号牌个人页**——本地生成"呼号 + 段位 + 通联风格"的分享图，不需要账号也能传播。
